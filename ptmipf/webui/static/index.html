Orientations already in the file

For a configuration another OVITO session has already run PTM on. Name the columns that hold the quaternions and they are coloured directly, with no second PTM run.

Boundary filling
Å

Unindexed atoms take the average orientation of the indexed atoms within the radius. An interpolation, not a measurement.

IPF projection direction
Sample frame (RD, TD, ND)

Assign a specific direction, in cell coordinates, to each named sample axis, e.g. RD = 1,0,0. Missing axes are completed to a right-handed triad. The named axes are what the IPF direction, the pole figure axes and the triad refer to.

System rotation

Turn the whole system, atoms and orientations together, about the cell centre. Rotations are applied in order, each about an axis of the fixed sample frame. Changing one recolours without running PTM again.

Selection
Selection needs the ptmipf.select module, which is not available in this installation.

Use your own colour scale

An image strip, read left to right, or a text file of RGB triples one per line in 0 to 1 or 0 to 255. A screenshot of the colour bar from a paper works, and so does the colour map this tool writes for OVITO. It is held in memory for this session only and never written to disk.

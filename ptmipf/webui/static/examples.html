A polycrystal to squash

Each of these builds a small cube of randomly oriented grains, downloads the matching EAM potential from the NIST Interatomic Potentials Repository, and writes a LAMMPS input that compresses it along z. Nothing is run for you: the files land in a folder under the directory this server is serving, and the run is sized to finish on a laptop while you make coffee.

Settings

The defaults are sized for a couple of minutes. Bigger cells and more grains look better and cost more; the estimate updates as you change them.
